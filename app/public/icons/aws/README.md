# Official AWS Architecture Icons

Source: the [`aws-icons`](https://www.npmjs.com/package/aws-icons) npm package (v3.3.0, MIT — see LICENSE.txt),
which repackages the official AWS Architecture Icons asset set (https://aws.amazon.com/architecture/icons/).

Files are renamed to the studio's catalog ids (`aws-lambda.svg` = Arch_AWS-Lambda_48, etc.).
Service icons live at `/icons/aws/<serviceId>.svg`; `group-*.svg` are the official
group/boundary icons (Region, VPC, subnet) used by container labels.
